# Sistema de Préstamo de Equipos Tecnológicos

**Proyecto Scrum — Desarrollo de un MVP en Python**
Curso: *Scrum y Metodologías Ágiles*

Este repositorio contiene el **incremento funcional (MVP)** y todas las
**evidencias de la aplicación de Scrum** durante un Sprint de una semana, para
el desarrollo de un sistema de préstamo de equipos tecnológicos de una
institución educativa.

---

## 1. Descripción del producto

Una institución educativa gestiona manualmente el préstamo de equipos
tecnológicos (portátiles, tablets, proyectores) a sus estudiantes, con
dificultades para registrar equipos, estudiantes, préstamos y devoluciones.

El MVP es una **aplicación de consola en Python**. El alcance de este Sprint son
las **tres primeras historias**, que construyen la base de datos del sistema:

- Registrar **equipos** (HU01).
- Consultar los **equipos** registrados y su disponibilidad (HU02).
- Registrar **estudiantes** (HU03).

La gestión de préstamos y devoluciones queda planificada para un Sprint
posterior. El código fuente y sus instrucciones de ejecución están en
[`09_Codigo/`](09_Codigo/README.md).
